# Wikilink

启用后，Typora 编辑区会将 Wikilink 显示为带下划线的链接文字；`[[笔记|别名]]` 显示别名。按住 Ctrl（macOS 为 Command）单击即可打开对应 Markdown 文件。原始 `[[...]]` 文本保持不变，仍可直接在 Obsidian 中使用。普通单击可恢复原文进行编辑。

支持 `[[笔记]]`、`[[文件夹/笔记]]`、`[[笔记#标题]]`、`[[笔记|别名]]` 和 `[[#当前文件标题]]`。查找顺序为当前文件所在目录、Typora 已打开的根目录，然后是根目录下同名 Markdown 文件。打开带标题的链接后会滚动到对应标题。

目前不处理 Obsidian 的 `![[嵌入]]`、块引用链接和输入时自动补全。
